# 🌳 choitree

[English](README.md) · [한국어](README.ko.md) · [中文](README.zh.md) · **日本語**

**Claude Code のライブパネル。ファイルツリー、git 状態、Claude の作業位置、トークン使用量、利用上限を表示します。現在のプロジェクト内だけが対象です。**

## 機能

- **ファイルツリー**：git が追跡するファイルから作ります。Claude が作業中・変更あり・最近開いたフォルダは自動で開き、それ以外はファイル数付きの 1 行にたたみます。
- **セッション**：使用中のモデルと、このプロジェクトで Claude が実際に作業した累計時間（ターン時間のみ、セッションをまたいで合算、待機時間は除く）。
- **git 状態**：ブランチ、リモートブランチと先行/遅れのコミット数、最新コミット、変更ファイル数、ファイルごとの記号（`●` 変更 · `+` 追加 · `?` 未追跡 · `✖` 削除 · `→` 名前変更）。
- **Claude の作業位置**：Claude が今読んだり編集したりしているファイルに `▶`、最近扱ったファイルに `← Read` / `← Edit`。
- **Claude キャラクター**：作業中に動き、使用中のツールと経過時間を表示します。
- **トークンと上限**：入力(↑)・出力(↓)トークン、セッション費用、コンテキストバー、Claude Code が報告するすべての利用上限（5 時間、週間、モデル別週間、支出）とリセット時刻。
- **ファイルアイコン**：60 以上の言語と設定・ドキュメント・メディア・圧縮ファイル。
- **言語**：韓国語、英語、中国語、日本語。

```
/plugin marketplace add choidevhi/choitree

```

## 使い方

- ターミナル幅が 144 桁以上ならセッション開始時に自動で開きます。`/choitree` でも開けます。
- マウス：フォルダをクリックで開閉、ファイルをクリックでプロンプトに `@パス` を挿入。
- キーボード：`ctrl+x tab` でパネルにフォーカス、`↑` `↓` で移動、`Enter` で開く/たたむ。
- 言語：既定は英語です。`/config` でプラグインの `language` オプションを `ko`、`zh`、`ja` に設定できます。

## プライバシーと範囲

**choitree はどこにも何も送りません。** ネットワーク通信をせず、ファイルを書きません。セッションをまたいで残すのは下記の作業時間の合計だけで、Claude Code のローカルプラグインストアに置きます。読み取った内容はパネルにだけ表示されます。

### 何を読み、どこへ行くか

| 呼び出し | 読むもの | 行き先 |
|---|---|---|
| `$.session.root()` | セッションのプロジェクトフォルダのパス | 他のすべての読み取りをそのフォルダ内に制限するために使用 |
| `$.process.run`（`git` のみ、下記参照） | プロジェクトフォルダのファイル名、ブランチ名、git 状態 | パネルに表示するだけ |
| `$.fs.list` | git リポジトリでない場合のみ、プロジェクトフォルダ直下のファイル・フォルダ名 | パネルに表示するだけ |
| `tool.call` フック入力 | ツールが扱うファイルパス。プロジェクト内のものだけ保持 | パネルに表示するだけ（`▶`、`← Read`） |
| `$.session.model()` | セッションが使うモデル名（`/model` の表示どおり） | パネルに表示するだけ |
| `$.session.usage()` / `turn.step` の結果 | Claude Code が既に持っているトークン数、セッション費用、コンテキストサイズ、利用上限 | パネルに表示するだけ |
| `$.store.get` / `$.store.set` | プロジェクトごとに数値 1 つ：Claude がそのプロジェクトで実際に作業した合計時間（各ターンの開始から終了まで）、プロジェクトパスをキーにする | お使いのコンピュータの Claude Code プラグインストアに保存され、セッションをまたいで累計。外部には送らない |
| `options.language` | プラグイン自身の `language` オプション | パネルの言語を選ぶ |
| `$.prompt.fill` | 読まない。ファイルをクリックするとプロンプトに `@パス` を書く | プロンプト入力欄 |

- **ファイルの中身は一切読みません。** 名前と git 状態だけです。
- **現在のプロジェクトのみ。** git リポジトリがプロジェクトフォルダより上から始まっても、フォルダ外のファイルは含めません。
- **コンピュータの設定値は読みません。** 言語はプラグインオプション（`user_config`）からのみ取得します。

### 実行するプログラム

プロジェクトフォルダで `git` だけを実行します。各コマンドは呼び出しの中に固定テキストとして完全に書かれています（`$.process.run(['git', ...], { cwd: root })`）：`git rev-parse --show-prefix`（リポジトリか確認）、`git branch --show-current`（ブランチ名）、`git rev-parse --abbrev-ref --symbolic-full-name @{upstream}`（追跡しているリモートブランチ）、`git rev-list --left-right --count @{upstream}...HEAD`（先行/遅れのコミット数）、`git log -1 --format=%h %s`（最新コミット）、`git ls-files`（ファイル一覧）、`git status --porcelain=v1 -uall -- .`（変更ファイル）。

### 各フックの役割

| フック | 役割 |
|---|---|
| `session.start` | `language` オプションを読み、`/choitree` を登録し、プロジェクトをスキャンしてパネルを開く |
| `command.run` | 再スキャンしてパネルを開く |
| `turn.start` / `turn.complete` | キャラクターのアニメーションを開始・停止し、ターン終了後に git 状態を再読み込み |
| `turn.step` | モデル応答ごとのトークン数を加算。応答はそのまま渡す |
| `tool.call` | ツールが扱うプロジェクト内ファイルを記録し、編集やシェルコマンドの後に再スキャン。ツール呼び出しを変更・阻止・遅延しない |
| `ui.render` | パネルを描画 |

追加するのはスラッシュコマンド 1 つ（`/choitree`）だけで、ツール、エージェント、MCP サーバー、システムプロンプトは追加しません。
