# 🌳 choitree

## 機能

- **ファイルツリー**：git が追跡するファイルから作ります。Claude が作業中・変更あり・最近開いたフォルダは自動で開き、それ以外はファイル数付きの 1 行にたたみます。
- **git 状態**：ブランチ、変更ファイル数、ファイルごとの記号（`●` 変更 · `+` 追加 · `?` 未追跡 · `✖` 削除 · `→` 名前変更）。
- **Claude の作業位置**：Claude が今読んだり編集したりしているファイルに `▶`、最近扱ったファイルに `← Read` / `← Edit`。
- **Claude キャラクター**：作業中に動き、使用中のツールと経過時間を表示します。
- **トークンと上限**：入力(↑)・出力(↓)トークン、セッション費用、コンテキストバー、Claude Code が報告するすべての利用上限（5 時間、週間、モデル別週間、支出）とリセット時刻。
- **ファイルアイコン**：60 以上の言語と設定・ドキュメント・メディア・圧縮ファイル。
- **コードビューア**：ファイルをクリックすると行番号付きで別パネルに開きます。
- **言語**：韓国語、英語、中国語、日本語。

## 使い方

- ターミナル幅が 144 桁以上ならセッション開始時に自動で開きます。`/choitree` でも開けます。
- マウス：フォルダをクリックで開閉、ファイル名をクリックでビューアに表示、`@` をクリックでプロンプトに `@パス` を挿入、`✕` でビューアを閉じる。
- キーボード：`ctrl+x tab` でパネルにフォーカス、`↑` `↓` で移動、`Enter` で開く/たたむ。ビューアでは `g`/`e` 先頭/末尾、`k`/`j` 前/次のページ、`a` で `@パス` 挿入、`x`/`Esc` で閉じる。
- 言語：既定では Claude Code の `language` 設定に従います。`/config` でプラグインの `language` オプションを `ko`、`en`、`zh`、`ja` に設定できます。

## プライバシーと範囲

- **外部には何も送りません。** choitree はネットワーク通信を行いません。
- **現在のプロジェクトのみ。** ツリー、git 状態、コードビューアはセッションのプロジェクトフォルダ（`$.session.root()`）内だけを扱います。コードビューアはシンボリックリンクを解決し、実際のパスがプロジェクト外のファイルは開きません。
- **使用量の数値**は Claude Code 自身（`$.session.usage()` とセッションのモデル応答）から得ており、API は呼びません。

### 実行するプログラム

プロジェクトフォルダで固定引数の `git` だけを実行します：`git rev-parse --show-prefix`（リポジトリか確認）、`git branch --show-current`（ブランチ名）、`git ls-files`（ファイル一覧）、`git status --porcelain=v1 -uall -- .`（変更ファイル）。

### 各フックの役割

| フック | 役割 |
|---|---|
| `session.start` | 言語設定を読み、`/choitree` を登録し、プロジェクトをスキャンしてパネルを開く |
| `command.run` | 再スキャンしてパネルを開く |
| `turn.start` / `turn.complete` | キャラクターのアニメーションを開始・停止し、ターン終了後に git 状態を再読み込み |
| `turn.step` | モデル応答ごとのトークン数を加算。応答はそのまま渡す |
| `tool.call` | ツールが扱うプロジェクト内ファイルを記録し、編集やシェルコマンドの後に再スキャン。ツール呼び出しを変更・阻止・遅延しない |
| `ui.render` | ツリーパネルとコードビューアを描画 |

追加するのはスラッシュコマンド 1 つ（`/choitree`）だけで、ツール、エージェント、MCP サーバー、システムプロンプトは追加しません。
